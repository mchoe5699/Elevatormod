# QWERTY's Elevator (Forge 1.20.1)

실제로 움직이는 카에 타고 이동하는 마인크래프트 엘리베이터 모드입니다. 승객용·전망용·화물용부터 패터노스터, 진공식, 경사형, 더블데크까지 여러 종류를 만들 수 있고, 카 크기·정원·속도·디자인을 제어반에서 바꿀 수 있습니다.

- Minecraft 1.20.1 / Forge 47.x
- 모드 ID: `qwertys_elevator`

## 빠른 설치 순서

1. **승강로 만들기**: 카가 지나갈 빈 공간(승강로)을 만듭니다. 1블록 = 1m입니다.
2. **승강장 문 설치**: 승강로 벽의 출입구 자리에 `승강장 문`을 놓습니다. 붙어 있는 문 블록은 하나의 문이 됩니다(예: 폭 2 × 높이 3). 문 블록의 앞면이 승강장(사람이 서는 쪽)을 향하게 놓으세요. 층마다 하나씩 놓습니다.
3. **제어반 설치**: `엘리베이터 제어반`을 아무 곳(기계실이나 승강장)에 놓습니다.
4. **링크**: `엘리베이터 링커`로 제어반을 우클릭한 뒤, 각 층의 승강장 문을 우클릭합니다. 층이 자동으로 등록되고 카가 생성됩니다.
5. **버튼·표시기 연결**: 호출 버튼, 홀 랜턴, 층 표시기, 행선층 패널 등도 링커로 우클릭해서 연결합니다. 연결된 부품은 가장 가까운 층을 자동으로 찾습니다.
6. **기계실 부품(선택)**: 권상기, 조속기, 유압 파워유닛을 링커로 연결하면 로프가 권상기까지 그려지고, 도르래가 카 속도에 맞춰 돕니다.

링커를 웅크리고 우클릭하면 연결이 해제되고, 허공에 웅크려 우클릭하면 링커가 초기화됩니다.

## 엘리베이터 종류

제어반 → 기본 탭 → 종류를 고른 뒤 "종류 기본값 적용"을 누르면 그 종류에 맞는 크기·문·속도·디자인이 한 번에 들어갑니다.

| 종류 | 특징 |
|---|---|
| 승객용 | 로프식(기계실), 2매 중앙개폐 |
| 기계실 없는(MRL) | 승강로 상부 기어리스 권상기, 2:1 로핑 |
| 유압식 | 피트의 유압 잭이 카를 밀어 올림, 저층용 |
| 전망용 | 유리벽, 반원형 뒷면 |
| 화물용 | 4×4m 카, 상하개폐 문, 체커 플레이트 바닥 |
| 자동차용 | 4×7m 카, 탈것도 함께 운반 |
| 침대용(병원) | 깊은 카, 3매 측면개폐, 양쪽 조작반 |
| 비상용 / 피난용 | 소방 1차 귀환 + 소방 2차 운전 |
| 주택용(홈) | 소형 카, 접이식 게이트, 스크류 구동 |
| 소형화물용(덤웨이터) | 사람이 탈 수 없고, 카에 27칸 보관함 |
| 경사형 | 아래 정류장은 앞문, 위 정류장은 뒷문(관통형)으로 연결하면 비스듬히 이동 |
| 더블데크 | 2층 카, 아래 데크는 홀수층·위 데크는 짝수층 |
| 초고속 | 600m/min, 보상 체인 |
| 패터노스터 | 멈추지 않고 순환하는 칸들. 승강장 문 폭을 카 폭 두 배 이상으로 만들고 문 형식을 "문 없음"으로 |
| 진공식(공압식) | 원통형 카와 유리 튜브 |
| 공사용 호이스트 | 메쉬 케이지, 랙 앤 피니언 마스트 |
| 휠체어 리프트 | 천장 없는 플랫폼, 여닫이 문 |

## 사용자화 (제어반 GUI)

- **크기**: 카 폭·깊이·높이(0.125m 단위), 카 좌우 위치, 출입구 폭·높이(자동 = 승강장 문 크기), 카 형태(사각/원형/반원형 뒷면), 문 형식, 데크 수, 피트 깊이, 오버헤드
- **정원**: 적재하중·정원을 직접 입력하거나, 카 바닥 면적으로 자동 계산(EN 81-20 / 국내 기준, 1인 65kg)
- **디자인**: 벽·바닥·천장·문·몰딩 재질(아무 블록 ID나 입력 가능), 벽 종류(벽판/유리/하부벽+유리/메쉬/난간/없음), 조명 색, 조작반 스타일과 위치, 표시기(LED 도트/LCD), 버튼 등 색, 핸드레일·거울·CCTV, 디자인 프리셋
- **성능**: 정격 속도(6~1260 m/min), 가속도, 문 열림 유지 시간, 문 개폐 시간, 균형추 위치, 기준층 복귀, 조명 자동 소등
- **층**: 층 이름(B2, B1, 1 … 자동 또는 직접), 서비스 층 설정, 4층→F 표기, 기준층/휴지층/소방 귀환층
- **운전**: 자동, 전용, 점검(▲▼ 누르고 있기), 소방 귀환, 휴지 운전, 주전원, 카 재생성
- **상태**: 현재 층, 속도, 하중, 점검 결과(승강로 간섭 검사, 권상기·조속기 미연결 등)

## 카 안에서

- 조작반 버튼을 직접 우클릭해서 누릅니다. 층 버튼을 웅크리고 누르면 호출이 취소됩니다.
- 조작반을 웅크리고 우클릭하면 큰 조작반 화면이 열립니다(층이 많을 때 편리).
- 정원(하중) 초과 시 부저가 울리고 문이 닫히지 않습니다. 문 사이에 사람이 있으면 다시 열립니다(세이프티 슈).
- 비상벨은 주변 플레이어에게 알림을 보냅니다.

## 부품

제어반, 권상기(기어드/기어리스), 조속기, 유압 파워유닛, 반향 도르래, 주전원 스위치, 가이드 레일, 레일 브래킷, 스프링/유입 완충기, 리미트 스위치, 착상 감지판, 승강로 조명, 피트 사다리, 피트 정지 스위치, 승강장 문(9가지 형식), 호출 버튼, 홀 랜턴, 층 표시기, 와이드 표시기(군관리), 행선층 예약 패널, 소방 운전 스위치, 정원 표지판, 내장재 블록 18종.

카와 함께 움직이며 자동으로 그려지는 부품: 카 프레임(상부 크로스헤드, 하부 세이프티 플랭크, 가이드 슈), 도어 머신, 카 상부 점검 운전반·난간·환풍기, 에이프런, 가이드 레일과 브래킷, 메인 로프, 균형추와 균형추 레일, 보상 체인, 조속기 로프, 이동 케이블, 완충기, 유압 잭, 랙 마스트, 진공 튜브, 스크류, 패터노스터 체인과 스프로킷.

## 그 밖의 기능

- **군관리**: 호출 버튼 하나에 제어반을 여러 개 연결하면 가장 빨리 올 수 있는 호기가 응답합니다. 와이드 표시기는 연결된 호기들을 나란히 보여 줍니다.
- **행선층 예약**: 패널에서 목적층을 고르면 배정된 호기를 알려 주고, 탑승하면 목적층이 자동 등록됩니다.
- **소방 운전**: 소방 운전 스위치에 엘리베이터 키를 쓰거나, 제어반에 레드스톤 신호를 주면 소방 귀환층으로 직행합니다. 비상용은 카 안 소방 버튼으로 2차 운전을 할 수 있습니다.
- **비상 해제키**: 엘리베이터 키로 승강장 문을 열 수 있습니다(카가 없으면 추락 위험). 문이 열려 있는 동안 엘리베이터는 멈춥니다.
- **관통형(뒷문)**: 카 뒤쪽에 반대 방향을 향한 승강장 문을 연결하면 뒷문이 생깁니다.
- 제어반의 비교기 출력 = 현재 층 번호.

## 빌드

GitHub Actions가 푸시마다 jar를 빌드하고, 서버 게임 테스트와 클라이언트 스크린샷 테스트를 돌린 뒤 Releases에 올립니다. 직접 빌드하려면:

```
./gradlew build
```

결과물: `build/libs/qwertys_elevator-forge-1.20.1-1.0.0.jar`
